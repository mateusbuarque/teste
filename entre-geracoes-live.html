        Modo estúdio (igual ao OBS)

        1. Ligue 🎬 Modo estúdio no monitor do programa. Aparecem duas telas: Prévia (amarela) e Programa (vermelha, o que está no ar).
        2. Clicar numa cena (ou teclas 1–9) só coloca na prévia — o público não vê.
        3. ⇄ Transição (ou Enter) leva a prévia pro ar com a animação; ✂ Corte seco troca na hora. Duplo clique numa cena leva direto.

        Editor de cenas

        1. Cada cena tem um fundo (arte do podcast, cor, imagem, transparente ou verde chroma) e uma lista de fontes, como no OBS.
        2. Fontes de texto aceitam variáveis: {ep} {titulo} {convidado} {proximo} {perfis} {contagem} {cronometro} {noar} {hora}. Se a variável estiver vazia (ex.: sem convidado), a fonte some sozinha.
        3. As fontes da live (letreiro, pauta, comentário, selo, faixa) aparecem quando você liga elas no painel. Posicione onde quiser em cada cena.

        Como ligar no OBS

        1. Abra este arquivo no Chrome — essa é a central, fica com você.
        2. Clique em 📺 Abrir tela de saída. Abre uma janela só com o que vai pra live (clique duplo nela = tela cheia).
        3. No OBS, crie uma cena com as câmeras e, por cima delas, adicione Captura de janela apontando para a janela “EG • Saída”.
        4. Nas cenas de câmera, use o fundo Verde chroma. No OBS: botão direito na captura → Filtros → Chroma Key (verde).
        5. As cenas com fundo cheio cobrem tudo — você só precisa de uma cena no OBS e troca o resto por aqui.

        Jeito alternativo (tudo dentro do OBS): Fonte de navegador com o link do botão “Copiar link” (“Arquivo local” desmarcado, 1920×1080) e esta central em Docas → Docas de navegador personalizadas com o endereço file:/// deste arquivo. Nesse modo o verde chroma vira transparente sozinho. A captura de janela é o mais garantido.
